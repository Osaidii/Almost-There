# Almost There. 
A Horror Mystery Game in Production.  
The game revolvs around a person who arrives for a job interview in a lonely and eerie place. Suddenly, he faints and wakes up in a weird yellow place. He must find his way out.

## Controls
1. WASD to Move. 
2. Mouse To Look Around. 
  
## Play
1. To play the game, go to the [latest release](https://github.com/Osaidii/Almost-There/releases) on this repository.
2. Download Almost.There.V0.2.exe file to your device.
3. Run this file.
4. Congratulations, The game a now launched.

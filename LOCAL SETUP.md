# Local Development Setup
1. Open the Official Godot Website (https://godotengine.org/) and download the setup for your device.
2. Unzip the folder and run the executable (not console).
3. Download the source code or clone this repository to get the project files and unzip the files.
4. In the Godot window, press import and then select the project.godot file from the project files you just downloaded.
5. Press Open and then Import.
6. The Godot editor will open Infront of you and load itself.
7. you have reached the stage where now you can modify the files and check the code or even run the game in the local development environment.
8. Thanks for reading.
